# Consul — ИИ-помощник по деньгам для малого бизнеса Узбекистана

[English](README.md) · **Русский**

Consul — карманный бухгалтер для небольших торговцев. Владелец пишет или говорит *«продал на 1 200 000 наличными»*, а Consul ведёт учёт, отвечает на вопрос **«сколько мне можно потратить сегодня?»**, считает налоги и кредиты, читает фото чеков и накладных, сравнивает цены с рынком и объясняет всё на узбекском или русском.

Сделан для Umummilliy AI Hackathon (Ташкент, 17–19 ноября 2026), задачи Палаты коммерции 20 и 21. Демо-персона: *Дильноза, сухофрукты, рынок Чорсу, ИП (YaTT)*.

> **Главное правило: все числа считает код, LLM только понимает язык и объясняет.** Число в ответе ассистента должно прийти из результата инструмента; иначе ответ отклоняется и вместо него возвращается шаблонный.

> ⚠️ Только справочная информация — **не налоговая, юридическая или кредитная консультация.** Налоговые правила взяты из Налогового кодекса ([lex.uz](https://lex.uz/docs/4674902), [soliq.uz](https://soliq.uz)) и требуют сверки с актуальной редакцией.

## Что умеет

| Раздел | Что получает пользователь |
|---|---|
| **Книга операций** | Единый источник правды (таблица `ops`): продажи, закупки, расходы, продажи в долг (nasiya), возвраты. Остатки наличных и карты, должники, прибыль, «можно потратить» после налога и резерва. Деньги — целые сумы, дни считаются по Asia/Tashkent. Отмена, идемпотентные записи. |
| **Чат Consul** | Парсер операций без LLM → черновик, который пользователь подтверждает; LLM-агент с инструментами для вопросов. Стриминг (SSE), сохранённые чаты, память о фактах, которые сообщил пользователь, узбекский и русский. |
| **Заземление ответов** | Инструменты: `get_today`, `get_months`, `list_debtors`, `get_obligations`, `compute_tax`, `compute_loan`, `query_ops` (безопасный поиск только для чтения по операциям самого пользователя), `market_prices`, `remember_fact`. Числа в ответе сверяются с выводом инструментов; имена клиентов попадают к модели только как `D1`, `D2`… |
| **База знаний** | Составленные вручную статьи (маржа, оборот, налоговые режимы, господдержка…) с источниками; лексический поиск, не векторный. Налоговые и льготные правила помечены «проверьте на soliq.uz». |
| **Фото** | `POST /photo` — модель зрения (kimi-k3 через шлюз) читает чеки, накладные и документы, возвращает поля, позиции и черновики операций. |
| **Голос** | Распознавание речи ElevenLabs (Scribe) и синтез (Eleven v3, понимает узбекский). Ответы озвучиваются, суммы читаются так, как их говорят люди («4,2 млн»). |
| **Калькуляторы** | Кредит (аннуитет / дифференцированный), налоги УзР, точка безубыточности — чистые функции на Go, публичные эндпоинты. |
| **Что если, план, отчёт для банка** | «Что если закуплю на 15 млн / возьму кредит 34 млн?», стартовый план, одностраничный финансовый отчёт для банка. |
| **Цены рынка** | Официальные недельные средние [narx.stat.uz](https://narx.stat.uz), анонимные медианы по базарам из чеков пользователей (только если товар покупали ≥ 5 разных пользователей) и собственная цена пользователя. |
| **Отчёт для Палаты** | Агрегаты для Палаты коммерции: только пользователи с согласием, группы меньше 5 не возвращаются, бутстреп-доверительные интервалы. Демо-выборка синтетическая и помечена как синтетическая. |
| **Приватность** | Экраны согласия, экспорт данных (CSV), удаление аккаунта, маскирование персональных данных перед любым вызовом LLM. |

## Архитектура

```
 браузер ──► nginx (TLS, основной хост, лимиты) ─┬─► Next.js 16 (SSR, standalone)   /
                                                 └─► Go API (net/http)              /api/v1/*
 Go-монолит из модулей — связь через интерфейсы, сборка в backend/cmd/api/main.go
   auth · user · ledger · consul (агент чата) · kb · vision · speech · calculator
   advisor · palata · prices · infrastructure (config, db, cache, llm, httpx, pii, ratelimit)
        │                         │
   PgBouncer ► PostgreSQL 17     Redis 7 (чёрный список JWT, кэш, лимиты, хеши OTP)
        │
   LLM-шлюз (OpenAI-совместимый) · ElevenLabs · narx.stat.uz
```

Почему так: Go даёт один небольшой бинарник и быстрые тесты денежной арифметики; Postgres с миграциями goose делает книгу операций транзакционной; PgBouncer позволяет многим соединениям делить маленький пул (режим transaction, поэтому pgx работает в simple protocol); Redis хранит короткоживущее состояние; Next.js SSR даёт быструю первую отрисовку на недорогих телефонах; nginx завершает TLS и ограничивает частоту запросов до того, как их увидит Go.

## Быстрый старт

Нужен Docker с compose v2. Go ≥ 1.27 и Node ≥ 20 — только для запуска тестов вне Docker.

```bash
make up          # создаёт .env со случайными секретами, самоподписанный сертификат, поднимает весь стек
make smoke       # сквозной сценарий на https://localhost
```

- Документация API (Swagger UI): `https://localhost/api/v1/docs` (сертификат самоподписанный, браузер предупредит).
- Для ассистента впишите в `.env` `BASE_URL`, `AI_API_KEY` (и при желании `AI_MODEL`), затем `docker compose up -d api`. Без LLM чат отвечает шаблонами.
- **Демо-вход:** задайте в `.env` `APP_ENV=demo` и `DEMO_OTP=123456` (и `docker compose up -d api`), затем войдите по телефону `+998901234567` с кодом **`123456`**. В этом режиме любой номер принимает демо-код, поэтому не включайте его на публичном боевом сервере. `make demo-reset` возвращает эталонную книгу (можно потратить = 4 200 000 сум).

```bash
make test        # тесты Go (+ vet)
cd frontend && npm install && npm test && npm run typecheck && npm run dev
```

Интеграционные тесты с PostgreSQL запускаются, если задан `LEDGER_IT_DSN` (см. `backend/internal/ledger/repo_integration_test.go`).

## API

Все маршруты находятся под `/api/v1`; контракт — [`backend/api/openapi.yaml`](backend/api/openapi.yaml). Ошибки всегда выглядят как `{"error":{"code","field","message"}}`. Для записи нужен заголовок `Idempotency-Key`.

| Группа | Эндпоинты |
|---|---|
| Авторизация | `/auth/otp/send`, `/auth/otp/verify`, `/auth/register`, `/auth/login`, `/auth/refresh`, `/auth/logout`, `/auth/demo` |
| Книга | `/ledger/today`, `/ops`, `/ops/parse`, `/ops/{id}`, `/debtors`, `/obligations`, `/forecast/whatif`, `/reports/bank` |
| Ассистент | `/consul/ask` (JSON или SSE), `/chats`, `/memory`, `/photo`, `/voice/stt`, `/voice/tts` |
| Калькуляторы | `/calculator/calculate`, `/calculator/tax`, `/calculator/breakeven`, `/calculator/rules` |
| Рынок и Палата | `/prices`, `/palata/report`, `/palata/report.csv` |
| Аккаунт | `/me`, `/me/business`, `/me/consent`, `/me/export.csv`, `DELETE /me` |

## Качество ассистента

Во встроенном стенде `api eval-chat` задаётся 54 вопроса (узбекский и русский) на эталонной книге; проверяются числа, отказы, темы, источники, задержка и откаты на шаблон.

```bash
docker compose exec -T api /api eval-chat        # локально
make eval-chat-vps MODEL=deepseek-v4.1-flash     # на сервере
```

Последний прогон на `deepseek-v4.1-flash`: **40 / 54 (74 %)**, 43 ответа дала сама модель, медиана 2,8 с, p95 5,8 с. Остальные откатываются на шаблон, в основном потому, что проверка чисел отклонила цифру, которую модель назвала без инструмента (вопросы про налоговые правила, «как увеличить прибыль»). Такая строгость сохранена намеренно: неверное число хуже шаблона. Другие модели на этом шлюзе показали худший результат (gemini-2.5-flash — 7/50).

## Деплой (VPS)

На сервер попадают только конфигурационные файлы; код доставляется образами Docker Hub.

```bash
make publish publish-web   # собрать и отправить xsenos/consul-api и xsenos/consul-web
make deploy                # скопировать compose и шаблоны nginx, docker compose pull && up -d
```

Настройки (`DOCKERHUB_USER`, `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_PATH`, `DEPLOY_DOMAIN`, …) лежат в `.env`. С доменом nginx отдаёт основной хост и сертификаты Let's Encrypt (`deploy/vps/letsencrypt.sh`). Защита хоста (вход SSH только по ключам, файрвол nftables с лимитами, fail2ban, ограничение журнала) применяется отдельно командой `make vps-host` из `deploy/vps/host`.

Полезные цели: `vps-ps`, `vps-logs`, `demo-reset-vps`, `palata-seed-vps`, `palata-refresh-vps`, `prices-seed-vps`, `prices-push-vps`, `eval-chat-vps`.

## Настройка

Всё читается из `.env` (см. [`.env.example`](.env.example)); секреты в репозиторий не попадают.

| Переменная | Значение |
|---|---|
| `BASE_URL`, `AI_API_KEY`, `AI_MODEL` | OpenAI-совместимый LLM-шлюз и модель по умолчанию |
| `AI_CHAT_MODEL`, `AI_CHAT_DEADLINE` | необязательная модель для чата и срок ответа (по умолчанию 20 с) |
| `APP_ENV`, `DEMO_OTP`, `DEMO_PHONE` | `APP_ENV=demo` включает фиксированный демо-код (`123456`) и `POST /auth/demo` |
| `POSTGRES_*`, `REDIS_PASSWORD` | база данных и кэш |
| `PEPPER`, `JWT_ACCESS_SECRET`, `JWT_REFRESH_SECRET` | секреты авторизации (создаются `make env`) |
| `ALLOWED_ORIGINS`, `COOKIE_SECURE`, `COOKIE_DOMAIN` | CORS и cookie |
| `DOMAIN`, `LETSENCRYPT_EMAIL` | TLS в продакшене |
| `ELEVENLABS_API_KEY` | ключ провайдера речи; без него `/voice/*` отвечает 503, интерфейс переходит на ввод текстом |
| `ELEVENLABS_VOICE_UZ/RU`, `ELEVENLABS_TTS_MODEL`, `ELEVENLABS_STT_MODEL` | необязательные голоса и модели (по умолчанию: готовый голос, `eleven_v3`, `scribe_v2`) |
| `DOCKERHUB_USER`, `DEPLOY_*` | публикация и деплой |

## Безопасность и данные

- Пароли и OTP: Argon2id с солью и pepper (с ограничением памяти), JWT access + refresh с ротацией и чёрным списком в Redis.
- Каждый обработчик берёт пользователя из JWT, а не из тела запроса.
- Лимиты запросов на трёх уровнях: зоны nginx, Redis на пользователя/IP, nftables на хосте. fail2ban банит повторных нарушителей.
- Никаких персональных данных в логах и промптах LLM: имена превращаются в `D1`…, телефоны, документы и номера карт маскируются.
- Статистика для Палаты: только с согласия, k-анонимность при k = 5.

## Известные ограничения

- `narx.stat.uz` не отвечает с нашего VPS (диапазон IP заблокирован). Цены скачиваются на машине разработчика и импортируются: `make prices-push-vps`. У Korzinka нет публичного API цен, поэтому он не подключён.
- Для голоса нужен `ELEVENLABS_API_KEY`, а ElevenLabs не обслуживает некоторые страны (исходящий IP нашего VPS в такой): задайте `ELEVENLABS_PROXY_URL` с прокси из поддерживаемой страны (или выполните `make voice-tunnel-install` на машине в такой стране: поднимется обратный SOCKS5-туннель как пользовательский сервис systemd, см. `deploy/tunnel/`), иначе `/voice/*` отвечает 503, а интерфейс переходит на ввод текстом. Отправка SMS не подключена (OTP только демо).
- Налоговые записи и меры господдержки составлены вручную, автоматической синхронизации с lex.uz нет.
- Во фронтенде остаются несколько статичных экранов (обучение, список господдержки в «Кредите», пресеты плана).
